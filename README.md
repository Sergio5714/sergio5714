# 👋 Hi, I’m Sergei
Hardware maker and open-source enthusiast.

🔬 This GitHub is reserved for my open-source contributions, hobby projects, and experiments.

My repositories focus on full-stack electronics design for ultrasound acquisition systems (**[WULPUS Pro Max](https://github.com/Sergio5714/wulpus-pro-max)**, **[WULPUS](https://github.com/Sergio5714/wulpus)**), tissue-mimicking phantoms (**[DOPFLOW](https://github.com/Sergio5714/dopflow)**), as well as related software projects such as **[PyBF](https://github.com/Sergio5714/pybf)** (ultrasound beamformer) and **[AEPUS](https://github.com/Sergio5714/AEPUS)** (image annotation tool).
